# ChessLab — анализатор шахматных партий

## Установка движка
Так как GitHub не позволяет загружать файлы больше 25 МБ, файл `.wasm` не включен в репозиторий. 
Скрипт `js/engine.js` автоматически скачивает его с надежного CDN.

1. Возьми свой файл `stockfish-19-single.js`.
2. Положи его в папку `js/`.
3. Готово! Движок будет работать локально из твоего репозитория.
