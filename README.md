# ChessLab — анализатор шахматных партий

Бесплатный веб-анализатор шахматных партий без backend и регистрации.
Загружаете партию с **Chess.com** или вставляете **PGN** — браузерный Stockfish
оценивает каждую позицию, классифицирует ходы и показывает, где были зевки,
ошибки и лучшие продолжения.

## Возможности

- **Stockfish в браузере** — движок работает в Web Worker, ничего не уходит на сервер.
- **Импорт с Chess.com** — вводите ник, подтягиваются последние партии через публичный API.
- **PGN** — вставка текста, загрузка файла или drag & drop.
- **Оценка каждого хода** — от «блестящего» до «зевка», с учётом потери вероятности победы.
- **Точность игроков** — accuracy и ACPL по формуле Lichess.
- **График преимущества** — клик по графику переводит к нужному ходу.
- **Лучший ход и вариант** — стрелка на доске и первые ходы главной линии.
- **Навигация** — кнопки, клики по списку ходов, стрелки клавиатуры.
- **Адаптивная тёмная тема** — телефон, планшет, десктоп.

## Структура

```

index.html
css/styles.css
js/
app.js          — состояние, события, рендер
config.js       — настройки и классификация ходов
engine.js       — обёртка UCI Stockfish
engine/sf-shim.js — worker-шим для загрузки движка с CDN
analysis.js     — оценка позиций и классификация

board.js        — доска cm-chessboard
graph.js        — график преимущества на canvas

```

## Запуск локально

Из-за ES-модулей открывать `index.html` двойным кликом нельзя — нужен HTTP-сервер.

```bash
# Python 3
python -m http.server 8080

# или Node.js
npx serve .
```

Откройте `http://localhost:8080`.

## Публикация на GitHub Pages

1. Загрузите файлы в репозиторий.
2. **Settings → Pages → Source: Deploy from a branch**.
3. Выберите ветку `main` и папку `/ (root)`.
4. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

Сборка не требуется: все библиотеки подключаются с jsDelivr.

## Технологии

- [Stockfish.js 10](https://github.com/nmrugg/stockfish.js) (asm.js, один файл, без WASM)
- [chess.js 1.4](https://github.com/jhlywa/chess.js)

- [Chess.com Published-Data API](https://www.chess.com/news/view/published-data-api)

## Как считается точность

Для каждой позиции движок возвращает оценку в сантипешках. Она переводится
в вероятность победы по логистической формуле Lichess. Потеря вероятности
между ходами определяет классификацию:

| Потеря win% ↕▾ | Классификация ↕▾ |
|---|---|
| −0 (лучший ход движка) | Лучший / Блестящий / Отличный |
| −< 2 | Отлично |
| 2–5 | Хорошо |
| 5–10 | Неточность |
| 10–18 | Ошибка |
| > 18 | Зевок |
⚙

Точность игрока считается по средней потере и формуле
`103.1668 * exp(-0.04354 * loss) - 3.1669`, ограниченной диапазоном 0–100.

## Ограничения

- Глубина анализа ограничена скоростью браузерного asm.js-движка. Для более
сильного анализа выберите глубину 14 или замените `ENGINE_CDN` в
`js/config.js` на локальную сборку Stockfish WASM (файл `.js` и `.wasm`
должны лежать рядом).
- Публичный API Chess.com имеет неофициальные лимиты; при частых запросах
возможен ответ 429.
- Классификация «блестящий ход» — эвристика (жертва + лучший ход), а не
абсолютная истина.
